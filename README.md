# Medical Ethics LMS Demo

A browser-based demonstration of a Learning Management System (LMS) focused on medical ethics education.

## Overview

This project demonstrates the student-facing experience of an online learning platform, including course navigation, educational lessons, video integration, and knowledge assessments. It is part of an ongoing LMS development project built to explore practical web application development and digital education.

## Features

- Course catalogue and navigation
- Lesson presentation
- Educational video integration
- Interactive knowledge assessments
- Responsive browser-based interface

## Technology Stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Project Status

Under active development.

This repository contains the static browser-based demonstration. Backend functionality such as secure student authentication, email verification, database persistence, and saved assessment results is being developed separately using Python, Flask, and SQLite.

## Purpose

This project demonstrates practical skills in frontend development, application design, user interaction, and the development of educational software.
